## Game
Based on the board game Dune (Gale Force Nine, 2019). A personal fan
project; the map, interface and artwork are original.

- footsteps.mp3: "Snow footsteps running" by qubodup, https://freesound.org/s/216570/ (provided by the project owner; the loudest 3 seconds, trimmed, faded and levelled)
- bid-1..8.mp3: "Bag of pistachio shells drops on wood" by zabuhailo, https://freesound.org/s/871411/ (provided by the project owner; eight drops, trimmed, faded and levelled)
- spice-1..3.mp3: provided by the project owner (spice blow landing; levelled and faded)
- battle.flac: provided by the project owner (Battle phase loop; made seamless and levelled, 22.05 kHz)
- card-slide.mp3: "slidecard04" by silverdubloons, https://freesound.org/s/817579/ (provided by the project owner)
- card-slap.mp3: "slap cards" by themfish, https://freesound.org/s/45821/ (provided by the project owner; one slap trimmed)
- harvest.flac: provided by the project owner (grain scooping loop for Spice Collection; made seamless and raised)

The five phase loops are stored as FLAC (lossless, so they still loop without a gap), with a WAV copy of each beside it that the game only fetches if a browser cannot decode FLAC.
